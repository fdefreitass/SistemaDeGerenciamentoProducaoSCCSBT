
# SCC Produção

Sistema de Gerenciamento de Produção e Conteúdos do SCC SBT.

## Objetivo

Centralizar o gerenciamento de materiais audiovisuais,
solicitações de gravação, atualizações e remoções da grade.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- PostgreSQL
